## About

I am a **Software Engineer focused on backend development, distributed applications, and system integration**. My primary stack is **C# and .NET**, alongside **Go, TypeScript, and Python** across backend development, web applications, and AI learning.

At **IQ Global**, I work on production applications across media, MedTech, and enterprise business domains. My experience includes API design, database modelling and optimisation, authentication, payment integrations, background processing, and deployment automation.
